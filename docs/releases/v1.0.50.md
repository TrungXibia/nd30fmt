## nd30fmt 1.0.50: bộ quy chuẩn mẫu mở, ai cũng tự cài được

- **Không cần khoá vẫn chạy được.** Thêm bộ quy chuẩn mẫu mở `config/sample/*_spec.yaml` cho cả ba chuẩn (văn bản hành chính theo Nghị định 30/2020/NĐ-CP, văn bản của Đảng theo Hướng dẫn 05-HD/VPTW, luận văn/đề án). Bộ mẫu gồm các quy định bắt buộc của văn bản gốc; đơn vị có thể sửa trực tiếp cho phù hợp.
- **Bộ đầy đủ vẫn mã hoá.** Có khoá `ND30_SPEC_KEY` thì ứng dụng dùng bộ đầy đủ (`config/*_spec.yaml.enc`); khoá sai thì báo lỗi, không tự chuyển sang bộ mẫu.
- `/healthz` có thêm trường `"spec"`: `"sample"` (bộ mẫu) hoặc `"encrypted"` (bộ đầy đủ).
- CI và PR từ fork/Dependabot chạy được không cần secret (dùng bộ mẫu).

### Cài đặt nhanh
```
git clone https://github.com/TrungXibia/nd30fmt.git && cd nd30fmt
cp deploy/.env.example deploy/.env    # đặt APP_TOKEN
cd deploy && docker compose up -d --build
curl -s http://127.0.0.1:8030/healthz # "spec":"sample"
```

### Tệp đính kèm
`_core.abi3.so`: lõi Rust dựng sẵn cho Linux x86_64 (glibc ≥ 2.17, Python ≥ 3.9), đặt vào `nd30fmt/`. `SHA256SUMS.txt`: mã băm để kiểm tra.
